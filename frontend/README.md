# atmosIQ Frontend Dashboard (Scaffolded for Phase 1+)

This directory will host the web frontend interface for visualization, policy decision support, and interactive source attribution analysis for Delhi AQI.

## Planned Features
- Interactive PM2.5 heatmap and sensor location map.
- SHAP attribution breakdown by environmental and human factors (stubble burning, industrial, vehicular, background).
- Policy intelligence simulation workbench.
