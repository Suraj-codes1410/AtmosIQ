# atmosIQ FastAPI Service (Scaffolded for Phase 1+)

This directory will contain the high-performance FastAPI microservice responsible for serving ML model predictions and SHAP attribution outputs to the Spring Boot orchestration layer.

## Planned Responsibilities
- Serve inference requests for PM2.5 prediction.
- Provide SHAP feature attribution metrics for policy analytics.
- Integrate with MLflow Model Registry for model serving.
